## AnimCube

`src/main/java/org/selliott/animcube/AnimCube.java` contains a modified version
of AnimCube 3.5b, created by Josef Jelinek in 2001-2004. The original AnimCube
code is not relicensed under Cubearoni's MIT license.

The original author's page describes AnimCube as freeware, permits use in web
pages and modification, asks users to email the author when using it in their
pages, and requests that modifications be shared with the author. These are
historical upstream terms, not an MIT license grant.

Source and terms: https://animcubejs.cubing.net/old/sources/AnimCube/

The upstream page also credits Karl Hornell's original applet and Lars Petrus's
derived applet as sources of ideas and some algorithms.

Cubearoni's changes include desktop launch support, solver integration, modern
Java compatibility, standard move notation, configurable colors and solve face,
and UI sizing fixes. See the README's AnimCube History section for context.
